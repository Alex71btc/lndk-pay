# Security Policy

## Supported Versions

Security updates are provided for the latest stable release of BOLT12 Pay.
Users are strongly encouraged to keep their installations up to date.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately
through GitHub:

https://github.com/Alex71btc/lndk-pay/security/advisories/new

Please do not disclose security vulnerabilities through public issues,
pull requests, social media, or public discussion channels before a
fix is available and disclosure has been coordinated.

Where possible, include:

- Affected version and deployment platform
- Description of the vulnerability
- Steps to reproduce
- Potential security impact
- Suggested remediation, if available

Never include wallet seeds, private keys, API passwords, macaroons,
or other sensitive credentials in your report.

## Responsible Disclosure

We welcome responsible security research and will make reasonable
efforts to investigate reported vulnerabilities, develop fixes,
and coordinate disclosure with reporters.

Please only test installations that you own or are explicitly
authorized to test.

## Bug Bounties

BOLT12 Pay is an independent, non-commercial open-source project.
There is currently no funded bug bounty program, and financial
rewards cannot be guaranteed.

Responsible security contributions are greatly appreciated.
Researchers may receive public acknowledgement, with their consent,
when a security advisory is published.

Thank you for helping keep BOLT12 Pay and its users safe.
