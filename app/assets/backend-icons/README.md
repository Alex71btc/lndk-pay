# Backend identification icons

Small transparent SVG adaptations of the LND and phoenixd marks supplied by
the user, for identifying configured backends in Setup and Pay. Geometry is
simplified for small UI sizes. These identify the corresponding projects;
they are not the BOLT12 Pay application logo or an endorsement.

LND: https://github.com/lightningnetwork/lnd
phoenixd: https://github.com/ACINQ/phoenixd

The LND adaptation uses a two-tone neutral-gray L (upright #404040, foot #626262) for contrast on dark UI
surfaces; the background is transparent. This is a UI adaptation, not an
unmodified official logo asset.
